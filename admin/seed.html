🌱 Firestore Seeder — Imali.biz Admin

One-time tool to migrate all pipeline.js parcels into Firestore. Run this once. After seeding, use add-parcel.html / edit-parcel.html to manage data.

Step 1 — Set Admin Password

The default admin password is imali-admin. Set a custom password here (stored as a SHA-256 hash in Firestore — never plain text).

Step 2 — Seed All Parcels into Firestore

Writes every parcel from data/pipeline.js into the Firestore parcels collection. Skips parcels that already have a matching UPI in Firestore.
